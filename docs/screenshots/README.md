# Captures d'écran SmartFlow

Ajoutez ici les captures d'écran de l'application, organisées par écran.

## Convention de nommage

Utilisez des noms simples et stables :

```text
overview-fr.png
overview-en.png
maintenance-fr.png
maintenance-detail-fr.png
logistics-fr.png
control-center-fr.png
alerts-fr.png
analytics-fr.png
simulation-fr.png
```

Pour une même section, ajoutez un suffixe numérique si plusieurs vues sont nécessaires :

```text
maintenance-01-fr.png
maintenance-02-fr.png
```

## Recommandations

- privilégier le format PNG ;
- capturer l'interface complète lorsque cela aide à comprendre la navigation ;
- utiliser une résolution desktop cohérente, idéalement 1920x1080 ;
- ne pas inclure de secrets, tokens ou données personnelles réelles ;
- préciser dans le README principal ce que montre chaque capture.

Les images placées dans ce dossier peuvent être référencées depuis le README principal avec :

```markdown
![Description de l'écran](docs/screenshots/nom-de-la-capture.png)
```
